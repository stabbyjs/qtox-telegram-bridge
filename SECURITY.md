# Политика безопасности

## Поддерживаемые версии

Исправления безопасности выходят только для последней версии. Перед тем как
сообщать о проблеме, обновитесь до актуального релиза из `main` и проверьте,
что баг ещё воспроизводится.

| Версия  | Поддержка |
| ------- | --------- |
| latest  | да        |
| старее  | нет       |

## Как сообщить об уязвимости

Не открывайте публичный issue по уязвимостям - так о проблеме узнают раньше,
чем выйдет фикс.

Пишите приватно на **stabbydev@pm.me**. По возможности приложите:

- описание проблемы и в чём заключается риск;
- шаги для воспроизведения или PoC;
- версию (коммит) и окружение, где это проявилось.

Я отвечу, как только разберусь, и согласую сроки раскрытия. Если нашли фикс -
присылайте, обсудим. Координированное раскрытие приветствуется.

## Что под угрозой в этом проекте

Мост держит у себя два по-настоящему чувствительных секрета:

- **Telegram bot-токен** - кто им завладел, тот управляет ботом и видит
  переписку, которая через него проходит.
- **Зашифрованный Tox-профиль** (`data/*.tox`) вместе с паролем шифрования -
  это идентичность вашего Tox-аккаунта и его контакты.

Утечка любого из них компрометирует мост целиком, поэтому относитесь к ним как
к паролям.

## Рекомендации по хранению секретов

- **`.env` не должен попадать в git.** Он уже в `.gitignore` вместе с `data/`,
  `*.tox` и `*.db` - не убирайте эти правила и не коммитьте файл руками
  (`git add -f`). Секреты держите только в `.env`, в репозитории остаётся лишь
  `.env.example` без значений.
- **Права доступа.** Профиль и базу храните только для своего пользователя:

  ```sh
  chmod 700 data
  chmod 600 data/*.tox data/bridge.db .env
  ```

  Каталог `0700`, файлы внутри `0600` - посторонние на машине не должны их
  читать.
- **Шифруйте Tox-профиль.** `TOX_PROFILE_PASSWORD` обязателен; незашифрованный
  профиль не используйте.
- **Не светите секреты в логах и issue.** При отправке отчёта или логов вырежьте
  токен, пароль и содержимое профиля.
- **Бэкапы - тоже секрет.** Копии `data/` и `.env` храните с теми же правами и
  по возможности зашифрованными.

## Зависимости

Проект линкуется с GPL-библиотекой libtoxcore и тянет привязку
`py-toxcore-c` из git. Обновляйте libtoxcore и зависимости вовремя - уязвимости
в нативном коде Tox напрямую затрагивают мост.
