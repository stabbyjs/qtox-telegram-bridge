# Архитектура

Мост - это один процесс на asyncio, который заменяет qTox: загружает твой
профиль `.tox`, держит ноду в сети Tox и зеркалит переписку в Telegram, где
каждый диалог живёт отдельным топиком в личном чате с ботом.

```
Tox-сеть  ⇄  ToxService (py-toxcore-c)  ⇄  Router  ⇄  TelegramService (aiogram)  ⇄  Telegram
                                            │
                                       Store (SQLite)
```

## Слои

Ядро не знает о конкретных SDK - оно общается с внешним миром через два
Protocol-интерфейса (`TopicSink`, `ToxSender`) из `interfaces.py`. Благодаря
этому `Router` и `Store` тестируются на заглушках, без системного libtoxcore.

- **config** - чтение и валидация настроек из окружения.
- **store** - SQLite: связь друг↔топик, дедуп, заявки в друзья, карта
  отправленных сообщений для отметок о прочтении.
- **settings** - переключатели поведения (уведомления, беззвучный режим,
  приём файлов) и список заглушённых диалогов. В памяти для быстрых проверок,
  с дублированием в Store.
- **file_transfer** - сборка входящих и выдача исходящих файлов кусками.
- **router** - вся логика маршрутизации и команды владельца. Чистый, без I/O
  кроме Store.
- **tox_service** - адаптер сети Tox: грузит профиль, крутит `iterate()`,
  превращает синхронные коллбэки toxcore в события на очереди.
- **telegram_service** - адаптер Telegram на aiogram: топики, файлы, команды.
- **app** - сборка зависимостей и запуск трёх сопрограмм.

## Поток данных

**Входящее (Tox → Telegram).** Коллбэк toxcore синхронный - он лишь кладёт
событие в `asyncio.Queue` (без `await`, потому что toxcore не потокобезопасен и
всё крутится в одном цикле). Отдельная корутина разбирает очередь, находит или
создаёт топик и шлёт сообщение/файл в Telegram.

**Исходящее (Telegram → Tox).** aiogram-хендлер ловит сообщение в топике,
определяет по `message_thread_id` нужного собеседника и отправляет его через
toxcore напрямую - гонок нет, так как всё в одном потоке.

## Что умеет

Личные сообщения и файлы в обе стороны, статусы и индикатор набора текста,
отметки о прочтении, аватары, заявки в друзья с кнопками, управление
контактами и своим профилем через команды, плюс меню настроек `/settings`
с переключателями и мьют отдельных диалогов через `/mute`.

## Чего пока нет

Групповые чаты Tox, аудио/видео-звонки и импорт старой истории из qTox - это
следующие шаги, см. README.

## Заметки по безопасности

- Команды и кнопки доступны только владельцу (сверка `from_user.id`).
- Имена файлов из сети чистятся (`safe_filename`), запись ограничена по
  позиции и размеру - без разреженных файлов на терабайты.
- Очередь событий ограничена, заявки в друзья дедуплицируются.
- Секреты живут только в `.env` (вне git), профиль шифруется паролем.
